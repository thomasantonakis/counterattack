# Online lobby codes

- Run the `OnlineLobbyCode` EditMode category for generation, pasted-code normalization, and missing or ambiguous search results.
- With two distinct EOS accounts in the same deployment, host in Multiplayer, copy the eight-character code, and join with it on the other client.
- Confirm both clients reach Match Setup, agree on settings, and enter Draft. Try a valid-looking nonexistent code and confirm it produces a clear error.
