# Online menu and desktop display verification

- Run the EditMode fixture `OnlineModeNavigationEditorTests` for authored button bindings, invalid code rejection, pasted code and control bounds.
- In the normal Windows and macOS players, start fullscreen, press F11, resize and maximize/restore or zoom, then press F11 again. Relaunch from windowed mode to check the fullscreen startup policy.
- Open Online Multiplayer, check Host opens setup, and return via Back. Paste a guest code and verify status, cancellation and return to the Online menu. Check labels and pointer targets in both display modes.
